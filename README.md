# Cats and Kills

Мрачный 2D top-down action / tactical shooter на Unity.

## Текущий этап

Сейчас собирается **v0.1 Vertical Slice**: один законченный боевой уровень, на котором проверяются основные механики игры.

Главный приоритет:
- ощущение оружия;
- групповой AI;
- укрытия, обходы и подавление;
- гранаты и возврат гранат;
- повреждения отдельных частей тела;
- отрыв конечностей и ползание тяжело раненых;
- разрушение лёгких укрытий;
- повреждённый военный ошейник;
- динамический темп боя.

## Unity

Версия проекта: **Unity 6000.5.10f1**.

После открытия проекта:

**Tools → Cats and Kills → Build Playable v0.1 Sandbox**

Команда создаёт сцену:

`Assets/CatsAndKills/Scenes/PlayableCombatSandbox.unity`

Сцена генерируется локально builder'ом и не должна считаться валидной, пока команда сборки не отработала без ошибок. Builder также обновляет Build Settings на эту сцену.

## Управление

- WASD — движение
- Shift — спринт
- Space — рывок
- мышь — прицел
- ЛКМ — огонь
- R — перезарядка
- 1 / 2 / 3 — оружие
- G — граната
- E — взаимодействие / отбросить ближайшую гранату
- Q — прототип способности повреждённого ошейника

## Графика

**Текущие примитивные визуалы не являются целевой графикой игры.**

Они оставлены только как fallback для проверки механик без зависимости от незаконченного набора ассетов. Целевое направление описано в [Docs/ART_DIRECTION.md](Docs/ART_DIRECTION.md).

Новый полноценный арт-комплект будет заменять placeholder целиком, а не постепенно украшать текущие кружки и квадраты.
